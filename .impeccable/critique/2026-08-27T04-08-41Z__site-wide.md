## Design Specificity Verdict

**The content is authored for J K Fertilizers; the chassis is a rental.** The MDX layer is genuinely specific (glomalin secretion, 100 IP/gm spore counts, per-acre dosing tables, PROM-vs-DAP chemistry) — no template ships that. But the surrounding chrome is category-interchangeable agency-template material: George Washington quote banner, marquee ticker, hand-duplicated testimonial cards, "Let's Cooperate Together" reused verbatim on 4 pages, stat bands cloned 4×. One artifact betrays it outright: `PageHero.tsx:49-54` renders a hardcoded overlay on every inner page reading "Built for serious B2B buyers… Cleaner positioning, stronger credibility, and fast action paths" — leftover internal design-brief commentary sitting on Products, About, History, Services, Portfolio, and Commitment heroes.

**Deterministic scan:** 2 findings, both `side-tab` (border-l-4) at `BlogPostPage.tsx:52` and `ServiceDetailPage.tsx:51` — **both false positives** (standard blockquote left-border typographic convention inside markdown renderer maps; the scanner lacks element context).

**Browser overlays:** Detector injected successfully on 5 pages of the stale `dist/` build (counts: home 81, products 46, product-detail 24, services 49, contact 22; examples: muted-text contrast 3.5:1 and 3.9:1, white-on-light 1.2:1, cramped padding). However, the flagged hex values (#8b7f6b, #edf0ea) do not exist in current `src/index.css` — that build is not the current source, so **no reliable overlay evidence exists for the code you will edit**. Rebuild `dist/` before any visual QA pass.

## Overall Impression

A credibility brochure that wants to be a sales instrument. The factory story is real and well-evidenced; the wrapper around it is template furniture with leftover authoring notes, and the commercial path (MOQ, tonnage, quotation) is a vacuum. Biggest single opportunity: turn the verified manufacturing proof into a frictionless quote funnel — and stop requiring farmers to invent a company name to submit a lead.

## What's Working

1. **Tokenized type/utility system (`src/index.css:88-276`)** — named semantic utilities (`type-body-sm`, `eyebrow`, exactly two shadows) consumed consistently; why 14 sections read as one document instead of collage.
2. **MDX product depth + honest engineering** — comparison tables (vs bentonite), HowToApply with real kg/acre doses, FCO framing, matching JSON-LD builders. This is the differentiation, delivered.
3. **Filter/search UX on /products** — URL-synced Fuse query, dynamic category counts, result counter, "Reset all," genuinely written empty state (`ProductsPage.tsx:151-251`).

## Priority Issues

**[P0] Desktop dropdowns are invisible-but-tabbable to keyboard users.**
Why: Both dropdowns open only via CSS `group-hover` (`SiteNavbar.tsx:169`, `:274`) — child links remain tabbable while `opacity-0 pointer-events-none`; Tab walks into 17 phantom focus stops; the entire product catalog is unreachable non-visually.
Fix: `group-focus-within:` variants + real toggle triggers with `aria-expanded` (Radix NavigationMenu is already in the dependency family).
Suggested command: `/impeccable harden`

**[P0] Required "Company" field blocks the farmer persona.**
Why: `InquiryForm.tsx:140-142` requires Company on the sole lead form; a farmer legitimately has none — persona #2 from PRODUCT.md is hard-blocked at the moment of conversion.
Fix: drop `required` from company, or split farm/B2B variants.
Suggested command: `/impeccable harden`

**[P1] Leftover authoring copy shipped on six page heroes.**
Why: `PageHero.tsx:49-54` — "Built for serious B2B buyers…" is meta-commentary about the redesign, not customer communication; it wastes every inner-page hero's money spot.
Fix: accept per-page `overlay` prop content (or remove).
Suggested command: `/impeccable clarify`

**[P1] Bulk-buyer conversion path has no commercial facts.**
Why: No MOQ, price tiers, bag formats, lead times, or toll terms rendered anywhere interactive; the form has no tonnage input and no "Quotation"/"Samples" inquiry options (`InquiryForm.tsx:179-184`). Bhavesh's evaluation loop dead-ends at "we'll discuss" — maximum friction exactly where PRODUCT.md defines success.
Fix: "Commercial Terms" block on product/service pages + tonnage input + inquiry-type options.
Suggested command: `/impeccable shape` then `/impeccable craft`

**[P1] Motion accessibility gaps.**
Why: `prefers-reduced-motion` block (`index.css:536-551`) omits the marquees (`AboutPage.tsx:269`, `HomePage.tsx:485`); Embla autoplay never pauses without hover (`HomePage.tsx:757`, `HistoryPage.tsx:240`) — WCAG 2.2.2 violation, vestibular trigger, wasted CPU on slow rural devices.
Fix: extend the media query to both animations; gate Autoplay behind `matchMedia`.
Suggested command: `/impeccable harden`

## Persona Red Flags

**Jordan (confused first-timer farmer):** hero sells MT/day before saying what the product does (`HomePage.tsx:38-39`); PROM/PDM never glossed on any product page (expansions exist only in `NotFoundPage.tsx:57-60`); mycorrhiza dosage sits below a soil-chemistry wall; **cannot submit the form** (Company required); "Coated Base Granules Bio NPK" nav label is gibberish to laypeople.

**Sam (keyboard/screen-reader):** invisible-but-tabbable mega menu (`SiteNavbar.tsx:168-171`); lightbox: no Esc, no backdrop close, no `role="dialog"` (`ProductDetailPage.tsx:251`); error banner lacks `role="alert"` (`InquiryForm.tsx:219-224`); mobile drawer has `aria-modal="true"` but background stays interactive and Esc does nothing (`SiteNavbar.tsx:332-340`); autoplay carousel can't be paused by keyboard at all.

**Casey (distracted mobile user, slow rural connection):** reveal classes start at `opacity: 0` (`index.css:426-432`) — on 2G with late JS, whole sections render blank until observers fire; three simultaneous infinite-motion systems on the homepage; primary CTAs at the very top of the viewport (only the pinned drawer-footer pair is thumb-zone); gallery arrows 40px (`h-10`, `ProductDetailPage.tsx:102`).

**Bhavesh (Bulk Buyer, B2B procurement — project persona):** verifies FCO/capacity/QC easily (credit due); finds zero MOQ/tier/lead-time data interactively; no COA/certificate PDFs; "samples" mentioned in copy but no sample-request entry point; must hand-type tonnage into a textarea beside requirement prose.
